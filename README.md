# Pomodora Clock

> A simple customizable Pomodoro timer to boost productivity.

---

## About

### What it does
A customizable Pomodoro clock that helps you break work into manageable time intervals with timer tracking and stopwatch functionality.

### Why I built it
I created this to help me start working by creating small time commitments, which helped me overcome the mountain that is a 2-hour study session.

### Who it's for
Students and workers who need help overcoming procrastination and staying focused during work sessions.

## Getting Started

### Prerequisites

- Python 3.13+
- uv

### Installation

1. Clone the repo:
```bash
git clone https://codeberg.org/Ryan-Goosen/pomodoraClock.git
```

2. Navigate into the project:
```bash
cd pomodoraClock
```

3. Setup environment:
```bash
uv venv
uv sync
```

4. Run the project:
```bash
uv run python src/pomodoraClock/main.py
```

---

## Usage

- **Timer tracker** - Track your work sessions
- **Pomodoro Clock** - Standard 25-minute work intervals
- **Stopwatch** - Simple time tracking
